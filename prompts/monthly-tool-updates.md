# AIコーディングエージェント 月次更新

`ai-coding-agent-updates` スキルを使用してください。
日本語の文章表現には `japanese-tech-writing` スキルも使用してください。ただし、簡潔さ、レポートのテンプレート、事実と推論の区別を優先してください。

Asia/Tokyoの `{YYYY-MM}` を対象に、保存済みweeklyを統合してください。

- weeklyの存在週と欠落週を明記する
- 対象月と重なるweeklyに欠落がある場合はcoverageをpartialとする
- 月内のcanonical updateを確認して二重計上を避ける
- 主要変化、共通トレンド、実務への影響を統合する
- 月内の日次と週次から公式イベントを製品更新と別に統合し、告知日・変更日で月内を判定して重複を除く
- 対象月より後の保存済み日次も確認し、告知日・変更日が対象月内の遅延発見を取り込む
- 日次・週次の欠落、旧形式でイベント欄がないレポート、イベント欄にある確認不能を引き継いで記録し、coverageをpartialとする
- 確認できた範囲の該当なしと確認不能を区別し、既存情報源に限るため網羅的でないことを明記する
- 対象外の有望なAIコーディングエージェントは、既存の公式情報源に現れた候補から探索する。バズやコミュニティ反応は調査しない
- 条件を満たす候補がなければ「対象外の有望ツール: なし」とする
- monthlyテンプレートでレポートをファイル書き込みツールまたはshellツールで保存する
