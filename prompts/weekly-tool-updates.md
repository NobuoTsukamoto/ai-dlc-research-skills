# AIコーディングエージェント 週次更新

`ai-coding-agent-updates` スキルを使用してください。
日本語の文章表現には `japanese-tech-writing` スキルも使用してください。ただし、簡潔さ、レポートのテンプレート、事実と推論の区別を優先してください。

Asia/Tokyoの `{YYYY-Www}` を対象に、保存済みdailyを統合してください。

- dailyの存在日と欠落日を明記する
- 同一更新や連続パッチをまとめる
- 日次の公式イベントを製品更新と別に統合し、同一イベントの告知・日程変更を1件にまとめる
- 対象週より後の保存済み日次も確認し、告知日・変更日が対象週内の遅延発見を取り込む
- 日次の欠落、旧形式でイベント欄がない日、日次のイベント欄にある確認不能を引き継いで記録し、coverageをpartialとする
- 確認できた範囲の該当なしと確認不能を区別し、既存情報源に限るため網羅的でないことを明記する
- バズやコミュニティ反応を調査しない
- weeklyテンプレートでレポートをファイル書き込みツールまたはshellツールで保存する
