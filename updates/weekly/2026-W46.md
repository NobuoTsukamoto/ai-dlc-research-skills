### GitHub Copilot CLI

- 主要変更: MSBuild向けC++ Language Serverがcompile commandsを自動生成するようになった。CLI 1.0.109〜1.0.112ではCIDR対応、permission ruleの正規表現、一時的なremote session作成、入力・session表示の修正などを公開した。password入力dialogはexperimentalのままstable版に含まれた。
- 流れ: C++環境の初期設定とpermission管理を改善しつつ、連続patchで対話操作やsession処理を修正した。1.0.110系列のpre-releaseで先行した変更はstable版にも反映されている。
- 実務への影響（推論）: MSBuild利用者は手動のcompile commands設定を省ける。管理者はpermission ruleとremote sessionの許可範囲を確認し、experimental機能は有効化の要否を分けて判断したい。
- 公式ソース: [C++ Language ServerのMSBuild自動設定](https://github.blog/changelog/2026-11-10-c-language-server-now-auto-configures-msbuild-builds)、[Copilot CLI 1.0.109](https://github.com/github/copilot-cli/releases/tag/v1.0.109)、[1.0.110](https://github.com/github/copilot-cli/releases/tag/v1.0.110)、[1.0.111](https://github.com/github/copilot-cli/releases/tag/v1.0.111)、[1.0.112](https://github.com/github/copilot-cli/releases/tag/v1.0.112)
