# AIコーディングエージェント週次まとめ 2026-W42

## 週の要点

1. 次世代フロンティアモデルと推論オーケストレーションの導入が進んだ。GitHub CopilotへGemini 4 Argonが追加され、工程別に推論強度を配分するHydraFusion（Maxオプション新設）が更新された。一方でCodexでのGPT-5.5提供終了やCopilotでの旧Opus・GPT-5.6の11月中旬廃止予告など、旧世代モデルの退役方針が明確化された。
2. エージェントの自律実行と安全制御の両立に向けた機能拡充が相次いだ。Google Antigravity CLIは不可逆操作のみ確認を求めるAuto modeやOSC 7501による端末状態通知を導入した。OpenAI Codex CLI 0.163.0は実行中処理の割り込み指示（steer）を新設した。Claude Codeはアイドル時のコンテキスト自動要約（idle compaction）やfork型サブエージェントの既定有効化を展開した。GitHub Copilotでは脆弱性を自律修正しPRまで作成・検証するAgentic autofixが一般提供された。
3. エコシステム連携と大規模開発環境の強化が進展した。Cursorは外部20サービス以上と接続するOrigin App Marketplaceを開設したほか、対話型キャンバス生成機能および最大300リポジトリ・起動速度5倍に対応したEnvironments API（beta）を提供した。またGitHub Copilotは組織設定の強制即時反映（フェイルクローズ）やSlack／Teams連携でのマルチリポジトリ操作に対応した。

## ツール別まとめ

### GitHub Copilot

- 主要変更: Googleの先端モデルGemini 4 Argonを一般提供し、従量課金制の下で各クライアントのモデル選択肢へ追加した。複数モデルを協調させるHydraFusionにおいて、工程別の推論強度自動調整やClaude Opus 5.5・GPT-6系の追加、高負荷タスク向けのHydraFusion Maxをプレビュー提供した。セキュリティ面では、CodeQL検証を経てドラフトPRを作成するAgentic autofixを一般提供した。また組織管理においてプロンプト内容を収集せずOpenTelemetryへ利用属性を付与するクライアントテレメトリ属性付与、起動時の管理設定強制取得（forceRemoteSettingsRefresh）によるフェイルクローズ制御、Slack／Teams連携における複数リポジトリ横断操作を導入した。あわせて、Claude Opus 4.8、Claude Opus 5、GPT-5.6 Terraを2026年11月16日に廃止する予定を告知した。
- 流れ: Gemini 4 ArgonやHydraFusionによる推論能力の向上とAgentic autofixによる脆弱性修正の自動化を進める一方、起動時ポリシー強制やテレメトリ監査の強化、旧世代モデルの計画的退役告知を行い、エンタープライズでの統制と世代交代を推し進めた。
- 実務への影響（推論）: コードスキャン警告の修正からPR作成・検証までを委譲できるようになり、セキュリティ対応の初動負荷を軽減しやすい。ただしAgentic autofixはAI CreditsとActions実行時間を消費するため予算管理が必要となる。11月中旬に予定される旧モデル廃止に向けて、固定プロンプトやモデルポリシーの後継モデル（Claude Opus 5.5やGPT-6系）への切り替え検証を計画的に進める必要がある。

### GitHub Copilot CLI

- 流れ: サンドボックス初期設定の安全性とディレクトリ権限の柔軟性を向上させつつ、最新モデル対応や宣言的フックによるカスタムエージェント拡張を整え、長時間実行時のメモリ枯渇やプロセス同期の安定化を図った。
- 実務への影響（推論）: 機密情報の誤送信防止とディレクトリ単位のアクセス許可により、安全確認の摩擦を抑えて作業を進められる。長時間セッションでのメモリ枯渇対策やフックの安定化により、大規模リポジトリでの自律タスク中断リスクが低下する。

### OpenAI Codex

- 主要変更: Codex CLI 0.163.0を安定版としてリリースし、0.164.0アルファシリーズを展開した。設定変更用の/configコマンド、応答生成中に対話を追加送信して即座に方向修正できる割り込み機能（steer）、リーダーキー設定（/keymap）、バックグラウンドサーバーの安全な再起動（/daemon）、独立した読み取りツールの並列実行を導入した。また2026年10月14日をもってChatGPTサインイン環境におけるGPT-5.5の提供を終了し、GPT-6.1 Sol（gpt-6.1-sol）への移行を案内した。
- 流れ: 応答中の割り込み機能や設定コマンドの整備により対話の操作テンポを改善しつつ、並列ツール実行による応答性能向上を図り、ChatGPT連携環境での旧世代モデル退役を完了させた。
- 実務への影響（推論）: エージェントが誤った方針で回答やコード生成を開始した場合でも、完了を待たずに即座に割り込んで軌道修正できるため、不要な待ち時間とトークン消費を抑えられる。GPT-5.5の提供終了に伴い、ChatGPT認証でCodexを利用している環境では固定モデル設定をGPT-6.1 Solへ切り替える必要がある。

### Claude Code

- 主要変更: バージョン2.1.299から2.1.302の安定版を連続リリースした。1時間のキャッシュ失効前に200K以上のトークンを要約するアイドル時コンパクション（/configで切り替え可能）、クライアント側の自動判定モデルを指定する環境変数（CLAUDE_CODE_AUTO_MODE_MODEL）、ファイルメンション時のパス渡し設定（CLAUDE_CODE_DISABLE_FILE_MENTIONS）、利用制限待機の打ち切り設定を導入した。fork型サブエージェントがSDK、デスクトップアプリ、VS Codeで既定有効化され、GUI環境でのサブエージェント実行が端末同様にバックグラウンドへ移行した。またUI拡張用のvirtualTextやprompt.changeフック、OpenTelemetryのGenAI属性拡充、Readツールの128MB上限、フック並行数制限（最大12件）を追加した。
- 流れ: アイドル時コンパクションやファイルメンション制御によりトークンコストの肥大化を防ぎつつ、自動判定モデル指定やfork型サブエージェントの既定化により並行処理の自律性とUI応答性を高めた。
- 実務への影響（推論）: セッション放置に伴うプロンプトキャッシュ失効と高額な再計算を回避しやすくなる。サブエージェントがGUIでも非同期に実行されるため、長時間作業中もエディタ操作が遮断されない。自動判定モデルを軽量モデルに固定することで、判断遅延とAPI費用の抑制が可能になる。
- 公式ソース: [Claude Code v2.1.299](https://github.com/anthropics/claude-code/releases/tag/v2.1.299)、[Claude Code v2.1.300](https://github.com/anthropics/claude-code/releases/tag/v2.1.300)、[Claude Code v2.1.301](https://github.com/anthropics/claude-code/releases/tag/v2.1.301)、[Claude Code v2.1.302](https://github.com/anthropics/claude-code/releases/tag/v2.1.302)

### Cursor

- 主要変更: 外部20サービス以上と連携するOrigin App Marketplaceを開設し、デプロイ、CI、静的解析、監視ツールのアプリ連携および一般開発者からの公開申請受付を開始した。クラウドエージェントにおいて対話作業から対話型キャンバスを作成・共有できるCanvases機能を追加した。またエージェント実行環境をプログラムから管理するEnvironments API（beta）を提供し、クラウドエージェントの上限を最大300リポジトリへ拡大して起動およびロード速度を従来の5倍に高速化した。
- 流れ: 前週のモバイル遠隔操作（Remote control）に続き、外部ツール連携のマーケットプレイス、成果物を視覚化するキャンバス、大規模マルチリポジトリに対応する実行基盤APIを整備し、クラウドエージェントを中心とした開発プラットフォーム化を進めた。
- 実務への影響（推論）: PR作成後の外部検証やデプロイをOrigin上で一元管理できるようになり、複数サービスの行き来が減る。エージェントの作成物をキャンバスとしてチーム共有できるため、設計や画面仕様の合意形成を迅速に行える。また大規模モノレポや多数の依存リポジトリを抱える環境でも、待機時間を抑えてクラウドエージェントを立ち上げられる。
- 公式ソース: [Origin App Marketplace](https://cursor.com/changelog/origin-app-marketplace)、[Cloud Agent Canvases and Environment Improvements](https://cursor.com/changelog/cloud-agent-canvases-and-environments)

### Google Antigravity CLI

- 主要変更: バージョン1.3.4から1.4.2をリリースした。安全なコマンドやファイル編集を自動承認し不可逆操作のみ確認を求めるAuto modeを導入し、サンドボックス外操作の事前審査を高速化した。OSC 7501による端末状態通知（実行中、入力待ち、完了、失敗）に対応した。プラグイン管理では一覧の--json出力、設定検証コマンド（agy plugin validate）におけるfrontmatterや命名重複の厳密検査、CI向け--strictオプションを追加した。また対話要約コマンド（/compact）、インライン差分プレビューの配色・行番号刷新、ADCログイン時のClaude 5.5系モデル対応、Windows非対応環境での事前確認フォールバックを実施した。
- 流れ: Auto modeとOSC 7501により端末作業の自律進行と状態把握の負荷を軽減しつつ、プラグイン検証の厳密化やインライン差分刷新、通信切断の自動再試行を通じて日常的な開発体験と拡張機能の品質基準を引き上げた。
- 実務への影響（推論）: 定型的な修正作業における手動承認の手間が大幅に削減され、端末タブの表示からエージェントの進行状況を把握できる。プラグインのメタデータ検査がCLI本体と一致したため、社内プラグインの自動テストやCI検証を組みやすくなる。
- 公式ソース: [Antigravity CLI 1.3.4](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.3.4)、[Antigravity CLI 1.3.5](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.3.5)、[Antigravity CLI 1.3.6](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.3.6)、[Antigravity CLI 1.4.0](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.4.0)、[Antigravity CLI 1.4.1](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.4.1)、[Antigravity CLI 1.4.2](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.4.2)
