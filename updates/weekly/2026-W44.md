# AIコーディングエージェント週次まとめ 2026-W44

## 週の要点

1. GitHub CopilotはUniverse 2026に合わせ、モデルの自動選択、チーム共有automation、Copilot Memory、pluginの企業統制などを拡充した。Copilot appではProjectsやComputer Use、セキュリティ拡張もプレビュー提供された。
2. エージェントの権限運用と組織導入に関する更新が続いた。Assisted PermissionsがGitHub Copilotで一般提供となり、Copilot SDK向けのserver-to-server認証はプレビューに入った。一方、Claude Codeはfast modeの廃止日を告知し、Antigravity CLIはGoogleサービスごとのURL承認を分離した。
3. Codex CLIとAntigravity CLIは複数の連続リリースをまとめて安定化を進めた。Codex CLIではVertex AI接続やthread再開・診断機能が加わり、Antigravity CLIでは画像入力、hook、プラグイン認証などが改善された。

## ツール別まとめ

### GitHub Copilot

- 主要変更: Assisted Permissionsが一般提供となり、安全と判定された操作を自動実行し、それ以外は承認を求める設定がVS Code、Copilot CLI、Copilot appに広がった。GPT-6.1 Terraも一般提供された。Universe関連ではCopilot Fusionの一般提供、GitHub Enterprise向けの予算ベース利用方式、Copilot Memoryの一般提供、Dreamingのpublic preview、pluginの既定値と企業統制、チーム共有型Copilot Automations、VS CodeのAgent Hostや複数クライアント間のセッション継続、画像生成・編集のpreviewが発表された。Copilot SDKを用いるGitHub Apps向けには、組織所有のidentityで利用するserver-to-server認証がpublic previewとなった。
- 流れ: エージェントに任せる操作の承認方法を整えると同時に、複数モデルの利用、共有ワークフロー、永続的な記憶、pluginを組織単位で管理する機能を揃えた。機能ごとにGA、preview、段階的展開が混在する。
- 実務への影響（推論）: 反復的な承認を減らしつつ組織ポリシーを適用でき、チーム単位でのエージェント導入を進めやすくなる。AIクレジットやモデル別料金を伴う機能が増えているため、previewを含め有効化範囲と費用計上先を確認してから展開したい。
- 公式ソース: [Assisted permissions GA](https://github.blog/changelog/2026-10-26-github-copilot-assisted-permissions-generally-available)、[GPT-6.1 Terra in GitHub Copilot](https://github.blog/changelog/2026-10-26-gpt-6-1-terra-in-github-copilot)、[server-to-server authentication](https://github.blog/changelog/2026-10-27-github-copilot-supports-server-to-server-authentication)、[Route and orchestrate models with GitHub Copilot Fusion](https://github.blog/changelog/2026-10-28-route-and-orchestrate-models-with-github-copilot-fusion)、[GitHub intelligence](https://github.blog/changelog/2026-10-28-github-intelligence-puts-your-code-context-and-history-to-work)、[Copilot Automations](https://github.blog/changelog/2026-10-28-build-shared-workflows-for-your-team-with-copilot-automations)、[GitHub Copilot in VS Code, Universe releases](https://github.blog/changelog/2026-10-28-github-copilot-in-vs-code-universe-releases)

### GitHub Copilot CLI

- 主要変更: 1.0.104をstableとして公開し、Assisted Permissionsをexperimental modeなしで利用できるようにした。対話型およびSDKのAutopilotセッションでは、接続中のバックグラウンドタスク完了を待つ挙動も改善された。続く1.0.105では長大なコンテキストでFusion High／Maxを選ぶ際の不具合を修正した。
- 流れ: Copilot全体の権限機能に追従しながら、長時間実行とモデル選択の安定性を高めた。
- 実務への影響（推論）: 定型コマンドの承認負荷を下げ、バックグラウンドタスクを含む対話を継続しやすくなる。Autopilotの待機条件は対話型・SDKと非対話実行で異なるため、CIなどでは既存のtimeout設定を確認したい。
- 公式ソース: [Copilot CLI 1.0.104](https://github.com/github/copilot-cli/releases/tag/v1.0.104)、[Copilot CLI 1.0.105](https://github.com/github/copilot-cli/releases/tag/v1.0.105)

### GitHub Copilot app

- 主要変更: Assisted Permissionsがアプリ内でも一般提供された。Universe関連では、複数リポジトリや資料を扱うProjectsと、利用者の承認を得てデスクトップを操作するComputer Useがpreviewとなった。security extensionもpreviewで提供され、code scanningアラートの調査やローカル作業コピーへの修正案作成に対応した。
- 流れ: 単一リポジトリの作業補助から、複数の作業対象を扱う機能やGUI操作、セキュリティ調査へ利用範囲を広げた。Projects、Computer Use、security extensionはpreviewである。
- 実務への影響（推論）: 複数リポジトリの作業や画面操作をアプリ内で進められる一方、Computer UseにはOS権限と操作前の承認が関わる。preview機能を試す場合は、組織設定、対象OS、AIクレジット消費を確認したい。
- 公式ソース: [Assisted permissions GA](https://github.blog/changelog/2026-10-26-github-copilot-assisted-permissions-generally-available)、[GitHub Copilot app, Universe releases](https://github.blog/changelog/2026-10-28-github-copilot-app-universe-releases)、[Security extension for the GitHub Copilot app](https://github.blog/changelog/2026-10-28-security-extension-for-the-github-copilot-app)

### OpenAI Codex

- 主要変更: CodexおよびChatGPT WorkでGPT-6.1 Terraの提供が始まり、Codex CLI 0.165.0ではGoogle Cloud Vertex AIプロバイダー、モデルカタログへのTerra追加、リポジトリ単位のセッション絞り込み、memory v2の既定化などが行われた。0.166.0ではtranscriptの選択・検索、`codex queue --resume`、接続診断用の`codex doctor --network-only`が加わった。0.165.0〜0.166.0のalpha更新は連続パッチとしてまとめた。
- 流れ: モデルの選択肢とクラウド接続先を増やし、複数セッションの管理や中断後の再開、障害診断を改善した。app-serverのthread分岐はexperimentalである。
- 実務への影響（推論）: Vertex AIを利用する環境ではCodex CLIの導入先を選びやすくなり、長い作業の再開や接続障害の切り分けもしやすくなる。GPT-6.1 Terraの提供プランや管理者設定、実験機能の提供条件は個別に確認する必要がある。
- 公式ソース: [GPT-6.1 Terra in Work and Codex](https://learn.chatgpt.com/codex/models?surface=app)、[Codex CLI 0.165.0](https://github.com/openai/codex/releases/tag/rust-v0.165.0)、[Codex CLI 0.166.0](https://github.com/openai/codex/releases/tag/rust-v0.166.0)

### Claude Code

- 主要変更: v2.1.311、v2.1.312、v2.1.314、v2.1.316がstableとして公開された。self-hosted runnerの実行維持、長大なコンテキストの自動圧縮、Entra IDを含むOIDC claim設定、CLAUDE.mdの誤上書き防止、作業ディレクトリ外への書き込み制限などが加わり、sandboxやCIでの失敗時の挙動も修正された。v2.1.316はOpus 4.8 fast modeを2026年11月30日に削除予定と告知した。
- 流れ: 長時間・大規模作業の継続性を改善しながら、ファイル書き込みやsandboxの権限境界を明確にした。fast modeについては機能追加ではなく、期限付きの廃止予告が含まれる。
- 実務への影響（推論）: 長いセッションや大きな指示ファイルを扱う際の中断・誤上書きを抑えられる。Opus 4.8 fast modeを利用するチームは、11月30日までに後継モデルへの移行と利用者への周知を進めたい。
- 公式ソース: [Claude Code v2.1.311](https://github.com/anthropics/claude-code/releases/tag/v2.1.311)、[v2.1.312](https://github.com/anthropics/claude-code/releases/tag/v2.1.312)、[v2.1.314](https://github.com/anthropics/claude-code/releases/tag/v2.1.314)、[v2.1.316](https://github.com/anthropics/claude-code/releases/tag/v2.1.316)

### Google Antigravity CLI

- 主要変更: stableの1.4.8〜1.4.12を公開した。差分画面の操作性・起動速度、画像貼り付け、失敗したツール呼び出しのエラー返却、会話再開時のCPU使用量を改善した。1.4.9ではGoogleの一般サイトとGmailやDriveなどの機密サービスのURL承認を分離し、1.4.11では`PreInvocation` hookによるモデル呼び出し前の停止、1.4.12ではプラグインのAPI key provider設定と未認証リクエストに対応した。
- 流れ: 連続パッチで操作性やリソース使用量を改善すると同時に、Webアクセス権限をサービス単位で分離し、hookによる入力制御やプラグイン認証を追加した。
