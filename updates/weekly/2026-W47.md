# AIコーディングエージェント週次まとめ 2026-W47

## 週の要点

1. GitHub CopilotはGPT-6.2やGemini 4 Neonの提供、コードレビュー機能、MCP連携を広げる一方、旧モデルの非推奨化とカスタマイズ管理を告知した。利用モデル、料金、組織ポリシーの確認が必要になる。
2. Copilot CLI、Claude Code、Antigravity CLIは短い間隔で複数リリースを重ね、管理者向け制御、権限・認証、セッションの安定性を更新した。とくにAntigravity CLI 1.5.14はWindows path経由の資格情報送信に関する修正を含む。
3. Codex CLIは0.171.0をstableとして公開し、TUI workspaceとremote session操作を拡張した。Copilot appもGHES連携をGAにし、Azure DevOpsとBrowser Useをpreviewで追加した。

## ツール別まとめ

### GitHub Copilot

- 主要変更: Claude Opus 4.8、Claude Opus 5、GPT-5.6 Terraの非推奨化と代替モデルを告知し、Local harnessはVS Code 1.146で非推奨、2027年2月に削除予定とした。GPT-6.2 Astra / SolとGemini 4 Neonを提供し、Adaptive code review、secret detection、Azure Repos向けレビュー、外部MCPコネクター、チーム既定のAgent Pluginsも追加した。
- 流れ: モデルとレビュー・連携機能を拡張する一方、モデルの移行やカスタマイズの配布元を管理する制御も加えた。新機能にはpreviewや段階的展開が含まれる。
- 実務への影響（推論）: 管理者は廃止対象モデルを使う設定とLocal harness依存を洗い出し、代替モデル、従量課金、preview機能の組織ポリシーを確認したい。
- 公式ソース: [モデル非推奨化](https://github.blog/changelog/2026-11-16-github-copilot-models-deprecated-on-november-16-2026)、[Local harnessの廃止予定](https://github.blog/changelog/2026-11-16-vs-code-retires-the-local-harness-in-february-2027)、[GPT-6.2の提供](https://github.blog/changelog/2026-11-17-openais-gpt-6-2-astra-and-gpt-6-2-sol-now-available)、[code reviewの更新](https://github.blog/changelog/2026-11-17-copilot-code-review-adaptive-effort-secret-detection-and-more)、[Gemini 4 Neon](https://github.blog/changelog/2026-11-18-gemini-4-neon-in-github-copilot)、[MCPコネクター](https://github.blog/changelog/2026-11-18-connect-supabase-box-calendly-and-more-to-copilot)、[チーム向けカスタマイズ](https://github.blog/changelog/2026-11-18-customize-github-copilot-for-your-team)

### GitHub Copilot CLI

- 主要変更: 1.0.113で管理者がBrowser Useを無効化できる設定がstableに入り、1.0.115の連続prereleaseではsandbox設定、モデル選択、Browser Use、ACP確認質問、plugin初期化、session再開、子プロセス終了などを修正・改善した。
- 流れ: 管理者制御やsandboxの調整と、長時間session・認証・プロセス管理の修正を同じprerelease系列で継続した。1.0.115の変更はprereleaseであり、stable提供は日次レポートでは確認されていない。
- 実務への影響（推論）: 既定sandbox動作と利用可能モデルが変わるため、prereleaseを試す場合は組織ポリシーと既存の自動化への影響を確認したい。

### GitHub Copilot app

- 主要変更: GitHub Enterprise Serverのリポジトリ連携をGAにし、Azure DevOpsリポジトリ連携とChromium系ブラウザーのBrowser Useをpublic previewで追加した。Copilot CLI、VS Code、JetBrains IDEからの連携も案内された。
- 流れ: GHESの利用範囲を広げるとともに、GitHub外のリポジトリとブラウザー操作へ対応を広げた。GHESとAzure DevOpsではcloud sessionを利用できない。
- 実務への影響（推論）: GitHub外のリポジトリを扱うチームは、既存のsession運用とpreview機能の有効化条件を確認したい。
