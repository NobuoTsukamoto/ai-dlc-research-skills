# AIコーディングエージェント週次まとめ 2026-W45

## 週の要点

1. GitHub Copilotは利用状況の計測項目と管理APIを拡充し、XcodeやJetBrains Airへの統合、Slack・Teamsでの開発依頼を広げた。Slack・Teams連携はGAとなった。
2. エージェントの権限境界と実行制御に更新が続いた。Claude Codeはhookやgatewayでの確認動作を変更し、Antigravity CLIは保護対象コマンドやpluginのアクセス境界を強化した。Copilot CLIもextensionのsandbox実行などを追加した。
3. Cursorはcloud agentによるWebアプリの構築・公開と、音声でのagent会話を追加した。Codex CLIのstable版では複数agentや未読結果の管理、Vertex AI接続などが改善された。

## ツール別まとめ

### GitHub Copilot

- 主要変更: Usage metrics APIにBYOK・組織独自モデルの利用量、code reviewの評価・対応状況、telemetryやIDE・extensionのバージョン状況が加わり、code reviewの設定APIやレビュー情報取得も拡張された。Xcodeのcoding assistantとJetBrains AirからCopilotを利用できるようになり、Slack・Teamsの@GitHub連携はGAとなった。VS Codeのagent・automation機能とCopilot appのAgent Mergeなども週次リリースで更新された。
- 流れ: 利用状況の把握と管理の粒度を上げる一方、IDE、コラボレーションアプリ、開発agentからCopilotを利用する経路を広げた。Xcode連携やVS Codeの一部機能はbeta、preview、experimentalであり、Slack・Teams連携はGAである。
- 実務への影響（推論）: 管理者はBYOKや独自モデルを含む利用状況を区別しやすくなり、開発者は既存のIDEや会話ツールから作業を依頼できる。利用条件や集計上の欠損、preview機能の権限・費用管理を確認したうえで、導入範囲を決めたい。
- 公式ソース: [BYOK and enterprise custom models in the Copilot usage API](https://github.blog/changelog/2026-11-03-byok-and-enterprise-custom-models-in-the-copilot-usage-api)、[Copilot code review API and review overview](https://github.blog/changelog/2026-11-06-copilot-code-review-api-management-and-review-overview-updates)、[Copilot in Xcode’s coding assistant](https://github.blog/changelog/2026-11-04-github-copilot-is-now-available-in-xcodes-coding-assistant)、[Copilot in JetBrains Air](https://github.blog/changelog/2026-11-03-github-copilot-is-now-available-in-jetbrains-air)、[@GitHub in Slack and Teams GA](https://github.blog/changelog/2026-11-06-github-copilot-in-slack-and-teams-is-generally-available)、[Copilot weekly releases — November 2](https://github.blog/changelog/2026-11-06-github-copilot-weekly-releases-november-2)

### GitHub Copilot CLI

- 主要変更: 1.0.106のstable公開では、VS Codeでのセッション再開、設定の統合・検索、オプトイン式のローカルセッション連携、sandbox内でのextension実行を追加した。1.0.107ではセッション管理や設定画面を続けて改善した。前後の1.0.106 prereleaseと1.0.108 prereleaseではACP・MCP、Windows、filesystem grant、repository indexingなどの修正・追加があった。
- 流れ: 設定・セッション管理をまとめ、extensionやMCPを扱う実行環境の制御を改善した。複数のprereleaseの変更は後続のstable版と重なるため、同一機能の段階的な公開として整理した。
- 実務への影響（推論）: CLIでの作業再開と設定管理がしやすくなり、extensionをsandbox内で動かす選択肢も増えた。prereleaseの機能やindexingの対象範囲は、組織配布前に確認したい。
- 公式ソース: [Copilot CLI 1.0.106](https://github.com/github/copilot-cli/releases/tag/v1.0.106)、[Copilot CLI 1.0.107](https://github.com/github/copilot-cli/releases/tag/v1.0.107)、[Copilot CLI 1.0.108-1](https://github.com/github/copilot-cli/releases/tag/v1.0.108-1)

### GitHub Copilot app

- 主要変更: 週次リリースで、PRのAgent Merge設定と待機中のcheck・ruleへの対応、reviewer状況、CSV・TSV添付、複数セッションの整理を改善した。補助承認の個人指示はローカルセッション向けのopt-in機能として追加された。
- 流れ: PRレビューからmergeまでの状態をアプリで扱いやすくした。補助承認は既定で有効になる変更ではない。
- 実務への影響（推論）: merge条件と承認担当をアプリ上で確認しやすくなる。opt-in設定の対象と、既存のレビュー承認手順との関係を確認したい。
- 公式ソース: [Copilot weekly releases — November 2](https://github.blog/changelog/2026-11-06-github-copilot-weekly-releases-november-2)

- 実務への影響（推論）: stable版によりagentの結果確認やVertex AI接続を扱いやすくなる。alphaを評価する場合は、タグ差分と実環境での挙動を別途確認したい。

### Claude Code

- 主要変更: v2.1.317〜v2.1.319をstableとして公開した。Agent SDK hookの失敗時に処理を止める設定、メールアドレス送信前の確認、認証期限の表示と警告を追加したほか、gatewayでauto modeのserver-side checkができない場合は自動許可へ代替しない挙動に変更した。MCP taskのバックグラウンド実行や各種permission・session修正も含まれる。
- 流れ: 連続リリースで、外部送信やhook、gateway経由の実行における確認・失敗時の扱いを明確にした。
- 実務への影響（推論）: hookやLLM gatewayを利用する環境では、処理が停止または確認要求に切り替わる条件を把握しておく必要がある。MCP taskを非同期化する場合は、完了通知と失敗時の運用も確認したい。
- 公式ソース: [Claude Code v2.1.317](https://github.com/anthropics/claude-code/releases/tag/v2.1.317)、[v2.1.318](https://github.com/anthropics/claude-code/releases/tag/v2.1.318)、[v2.1.319](https://github.com/anthropics/claude-code/releases/tag/v2.1.319)

### Cursor

- 主要変更: cloud agentがWebアプリの構築、Postgres準備、Cursor SSO認証、hosting設定を行い、セキュリティ検査と明示的な公開操作を経て共有リンクを作れるようになった。Agents Window、IDE、web、iOSではagentとの音声会話も追加された。
- 流れ: コード生成に加えて、アプリの試作・共有や音声での作業依頼へ利用範囲を広げた。Live Appsは有料プランとcloud agentsが必要で、対応repositoryにも制限がある。
- 実務への影響（推論）: 試作から共有までの手順を短縮できる一方、公開権限や秘密情報への接続を既存のレビュー手順と合わせて管理したい。音声利用では対象surfaceとPrivacy Modeの条件を確認する必要がある。
- 公式ソース: [Build Live Apps in Cursor](https://cursor.com/changelog/build-live-apps)、[Voice Chat with Agents](https://cursor.com/changelog/voice-chat)

### Google Antigravity CLI

- 主要変更: stable 1.5.0〜1.5.3でACP server mode、remote agent実行、local projects管理、ACP clientへの利用可能モデル提示を追加した。保護対象コマンドをskip-permissions設定でも確認対象にし、管理者が要審査にした範囲外アクセスを自動許可しないようにした。plugin名のpath検証、workspace境界、永続terminalのpath traversal対策も強化した。
- 流れ: ACP経由の接続先を広げながら、plugin・terminal・管理者ポリシーに関わる権限境界を修正した。連続patchを単一の1.5系更新としてまとめた。
- 実務への影響（推論）: ACPやremote agentへの接続を拡張できる一方、自動許可設定やworkspace外資源に依存する既存workflowは更新後に検証したい。
