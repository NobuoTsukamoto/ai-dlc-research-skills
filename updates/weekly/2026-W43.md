# AIコーディングエージェント週次まとめ 2026-W43

## 週の要点

1. 組織統制と監査の自動化基盤が大きく進展した。GitHub CopilotはEnterpriseやOrganization向けのモデルポリシー管理REST APIを一般提供し、未設定機能へのグローバルデフォルト強制適用を開始した。さらにUsage metrics APIを拡張して、社内のカスタムスキルやMCPサーバー名、外部クライアント（Claude Code、Codex、Zed等）経由の利用メトリクス集計に対応した。
2. エージェントのサンドボックス堅牢化とセキュリティ境界の再設計が相次いだ。Claude Code v2.1.309はmacOS/Linuxにおけるサンドボックス外実行やパスすり抜けなど複数の重大脆弱性を修正し、安全イベントのOpenTelemetry出力を導入した。Google Antigravity CLIは~/.dockerや~/.kubeを既定で保護対象とし、フック入力へのプロンプト情報付与を追加した。OpenAI Codexもリモートセッションでの認証情報マスキングを導入した。
3. 端末操作性と自律実行の最適化が進んだ。GitHub Copilot CLIは1.0.100から1.0.103を安定版として公開し、サブエージェントでの構造化出力対応、親ツールの承認状態継承、非対話実行でのAutoモデル適用を導入した。OpenAI Codex CLI 0.164.0はプロンプトやコマンドを保存できる/presetsコマンドを提供した。Antigravity CLIはWindows 11でのAuto mode展開や差分ビューの検索強化、アイドル時CPU消費の半減を実現した。

## ツール別まとめ

### GitHub Copilot

- 主要変更: 旧世代の6モデル（Gemini 3.7 Flash、GPT-5.5、GPT-5.4、GPT-5.4 mini、GPT-5 mini、Grok 4.5）の提供を終了し、後継モデルへの移行を案内した。組織管理面では、EnterpriseからOrganizationまでの4階層でモデルポリシーを取得・更新できるREST APIを一般提供した。また未設定の一般提供機能に既定ポリシーを適用するグローバルデフォルトの段階的ロールアウトを開始した。メトリクス面では、組織作成のカスタムスキル、カスタムエージェント、MCPサーバー名を出力可能としたほか、外部クライアント経由の利用量を集計するtotals_by_client配列を追加した。クライアント統合では、Visual Studio 2026向けにPR探索対応のGit agentやBYOM（プレビュー）を提供し、Microsoft Teams向けGitHubアプリにおいてIssue通知からの自動修正・PR作成連携を導入した。
- 流れ: 旧世代モデルの退役を完了させつつ、モデル管理APIやグローバルデフォルトによる組織ガバナンスのコード化を推進した。同時にメトリクスAPIの拡充により社内資産や外部ツールの利用実態を可視化し、チャットツールやIDEでのエージェント作業動線を整備した。
- 実務への影響（推論）: モデルポリシーのAPI化とグローバルデフォルト適用により、大規模組織での設定統制とプロビジョニング自動化が進む。未設定の機能が自動で有効化または無効化される可能性があるため、管理者は組織ポリシーの棚卸しを優先する必要がある。またカスタムエージェントや外部CLI経由のトークン消費をサーバー側で測定できるようになり、開発基盤の費用対効果検証や利用規程の策定が容易になる。

### GitHub Copilot CLI

- 主要変更: 安定版1.0.100から1.0.103を公開し、プレリリース1.0.104シリーズを展開した。テレメトリ停止フラグ（--disable-client-telemetry）やパス別指示（.github/instructions）の自動適用、動的ワークフローサブエージェントでのネイティブ構造化出力を追加した。サブエージェントが親ツールの承認状態を継承する仕組みを導入し、プロンプト実行（-p）時の管理下Autoモデル選択遵守、ディレクトリ移動コマンドでの承認改善、回答コードブロックのワンクリックコピーに対応した。また長時間コマンドの実行安定化やGeminiツール呼び出しエラーの修正、複数ワークツリー間でのローカルMCP共有を実装した。
- 流れ: セキュリティやテレメトリの制御を強化しつつ、サブエージェントの出力構造化と権限継承によって階層的タスク実行の自律度を高め、非対話実行や複数ワークツリーでの開発体験を安定させた。
- 実務への影響（推論）: サブエージェントからの返戻値が構造化されたことで、後続の自動化スクリプトやCIワークフローとの連携が安定する。親の権限をサブエージェントが引き継ぐため、階層型タスクの実行途中で承認待ちによって作業が止まる頻度が下がる。

### Google Antigravity CLI

- 主要変更: バージョン1.4.3から1.4.7の安定版を公開した。Windows 11（24H2以降）の個人アカウント向けにAuto modeの提供を開始した。ターミナルサンドボックスの既定設定を強化し、~/.docker、~/.kube、~/_netrcへのアクセスをデフォルト禁止とした。また/diffにおけるインクリメンタル検索・折りたたみ行内マッチ数表示、フックへの直前入力（lastUserInput）付与、プラグイン画面でのMCP変数再構成、画面非更新時の描画停止によるアイドル時CPU消費の半減を導入した。
- 流れ: Windows環境での自律実行機能の解放と機密ディレクトリの既定保護を推し進めつつ、差分検索の操作性向上や描画負荷の低減を通じて日常的なCLI開発体験を洗練させた。
- 実務への影響（推論）: Windows環境でも不可逆操作のみ承認を求める自律モードが利用可能になり、作業効率が向上する。一方でDockerやKubernetesの認証情報が既定で遮断されるため、コンテナ操作やクラスタデプロイを伴うタスクでは明示的なアクセス許可の設定が必要となる。
- 公式ソース: [Antigravity CLI 1.4.3](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.4.3)、[Antigravity CLI 1.4.4](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.4.4)、[Antigravity CLI 1.4.5](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.4.5)、[Antigravity CLI 1.4.6](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.4.6)、[Antigravity CLI 1.4.7](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.4.7)
