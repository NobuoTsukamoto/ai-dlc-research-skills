- バージョン / 提供段階: 2.1.284 / stable
- 重要度: high
- 変更内容（要約）: Claude Code v2.1.284がリリースされた。Anthropic APIの標準SonnetとしてClaude Sonnet 5.5（`claude-sonnet-5-5`、1Mコンテキスト）を追加した。対話型端末およびVS Code環境において、権限モード未設定時の既定動作をautoモードに変更した。autoモードで作業ディレクトリ外の読み取り前に「許可して次回も尋ねる」選択肢を追加した。`/mcp reconnect all` による全MCPサーバーの一括再接続、Ultracodeの独立トグル化、ゲートウェイ消費制限の金額表示、長文プロンプト圧縮の再試行、再開時のMCPサーバー接続待機（最大10秒）など多数の機能追加と修正を行った。

- 重要度: medium
