- 重要度: high

### GitHub Copilot CLI

#### [Copilot CLI 1.0.104](https://github.com/github/copilot-cli/releases/tag/v1.0.104)

- 公開日: 2026-10-27
- バージョン / 提供段階: 1.0.104 / stable
- 重要度: medium
- 変更内容（要約）: Copilot CLI 1.0.104が安定版として公開された。実験モードを有効化することなくAssisted Permissionsを利用可能になった（“without enabling experimental mode” (https://github.com/github/copilot-cli/releases/tag/v1.0.104)）。マネージドモデルfusionがAutoでセッションを開始してfusionTier設定を適用するよう改善された。また対話型およびSDKのAutopilotセッションにおいて、タイムアウトで終了せず接続されたバックグラウンドタスクの完了を待機し続けるようになった（-p --autopilotはタイムアウト設定を維持）。保存されたAutoモデル設定が利用できなくなった際に、ターンごとに失敗せず既定設定へフォールバックする修正が入った。
- 制約: 全プラットフォーム対象。Assisted Permissionsは対話コマンド/permissions等で設定。Autopilotの待機挙動は対話型およびSDKセッションに適用され、-p --autopilotはCOPILOT_TASK_WAIT_TIMEOUT_SECONDSに従う。
- 実務への影響（推論）: コマンドライン対話で実験的フラグを指定せずに安全なコマンドの自動実行を利用できるようになる。Autopilotセッションで長時間のバックグラウンドタスクがタイムアウトで打ち切られなくなるため、ビルドやテストを伴う重いタスクの自律実行が途中で中断するリスクを低減できる。
