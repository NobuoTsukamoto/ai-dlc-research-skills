### GitHub Copilot

#### [GitHub Copilot models deprecated on October 19, 2026](https://github.blog/changelog/2026-10-19-github-copilot-models-deprecated-on-october-19-2026)

- 公開日: 2026-10-20
- バージョン / 提供段階: 該当なし / stable
- 重要度: high
- 変更内容（要約）: GitHub Copilotの主要機能（Chat、インライン編集、ask/agentモード、コード補完）において、旧世代の6モデル（Gemini 3.7 Flash、GPT-5.5、GPT-5.4、GPT-5.4 mini、GPT-5 mini、Grok 4.5）が提供終了となった（“across most GitHub Copilot experiences” (https://github.blog/changelog/2026-10-19-github-copilot-models-deprecated-on-october-19-2026)）。公式の移行先としてGemini 3.8 Flash、GPT-6.1 Sol、GPT-6 Luna、Grok 4.7が提示されている。Enterprise契約では管理者がCopilot設定のモデルポリシーで代替モデルへのアクセスを許可する必要がある場合がある。非推奨モデルの削除に関する利用者側の能動的な作業は不要である。
- 制約: Copilot Chat、インライン編集、ask/agentモード、コード補完に適用。Enterprise組織では管理者が代替モデルへのアクセスを許可している必要がある。
- 実務への影響（推論）: 廃止対象のモデルを開発業務やエージェントの固定設定で利用していた組織では、後継モデルへの移行対応とプロンプト応答の挙動確認が必要になる。特にEnterprise環境では、管理者がポリシー側で新モデルの利用を明示的に許可していない場合、エディタ上のモデル選択肢から消滅して開発者の作業が滞る可能性があるため、管理者によるポリシー設定の点検を早急に進めることが望ましい。

#### [Copilot model policy API for enterprise, orgs, and teams](https://github.blog/changelog/2026-10-19-copilot-model-policy-api-for-enterprise-orgs-and-teams)

- 公開日: 2026-10-20
- バージョン / 提供段階: REST API / stable
- 重要度: medium
- 変更内容（要約）: Copilotのモデルポリシーを取得および更新するためのREST APIが一般提供された（“retrieve and update Copilot model policies” (https://github.blog/changelog/2026-10-19-copilot-model-policy-api-for-enterprise-orgs-and-teams)）。Enterprise（`/enterprises/{enterprise}/copilot/model-policies`）、Enterprise teams、Agent apps、Organizationの4階層を対象にGETとPATCHのエンドポイントが公開された。Enterprise全体のポリシーを通じて、組織モード配下のOrganizationや、Enterprise teamsモード配下のチームおよびエージェントアプリへモデル管理の制御権限を委譲できる。
- 制約: Enterprise、Enterprise teams、Agent apps、Organizationの管理権限が必要。
- 実務への影響（推論）: 大規模組織において、モデルの利用許可や制限ルールをWebコンソールの手作業ではなく、設定管理コードやプロビジョニング自動化基盤から統括できるようになる。新規モデルの段階的な組織展開や、特定エージェント専用の利用枠設定をCI/CD等のワークフローからプログラマブルに制御できるため、全社的なガバナンス維持と運用工数の削減につながる。
