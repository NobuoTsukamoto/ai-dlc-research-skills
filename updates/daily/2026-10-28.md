### GitHub Copilot

#### [GitHub Copilot supports server-to-server authentication](https://github.blog/changelog/2026-10-27-github-copilot-supports-server-to-server-authentication)

- 公開日: 2026-10-28
- バージョン / 提供段階: パブリックプレビュー / preview
- 重要度: medium
- 変更内容（要約）: GitHub Copilotにおいて、Organizationに導入したGitHub Apps向けのサーバー間（server-to-server）認証がパブリックプレビューとして提供された。Copilot SDKで構築したエージェントやバックエンドサービスが、個別ユーザーの資格情報に依存せず、組織が保有するワークロード専用の識別情報（“workload-owned identity” (https://github.blog/changelog/2026-10-27-github-copilot-supports-server-to-server-authentication)）でリクエストを発行できる。GitHub Appに「Copilot Requests（読み取り専用）」権限を設定し、短時間のインストールアクセストークンをSDKに渡して利用する。消費量や費用はインストール先組織へ請求され、組織のモデルポリシーや予算上限が適用される。管理者は利用状況CSVのapp_client_id項目でアプリごとの消費を追跡でき、アプリの停止や削除でアクセスを遮断できる。
- 制約: OrganizationにインストールしたGitHub AppsおよびGitHub Copilot SDKの利用環境が対象。パブリックプレビュー段階。「Copilot Requests」読み取り専用権限が必要。短時間有効なインストールアクセストークンを使用する。
- 実務への影響（推論）: CI/CDや自動実行エージェントを本番運用する際、特定開発者の個人アクセストークン（PAT）に依存する運用を廃止できる。従業員の異動や退職に伴うトークン失効で自動処理が停止する事態を防ぎやすい。さらに組織管理者はアプリ単位で使用量やコストを個別に監査できるため、社内エージェントの利用ガバナンスと予算管理を両立させやすくなる。

- 公開日: 2026-10-28

- 公開日: 2026-10-28
- バージョン / 提供段階: v2.1.312 / stable
- 重要度: medium
- 変更内容（要約）: Claude Code v2.1.312が安定版として公開された。Claude apps gatewayにおいてMicrosoft Entra IDのoidなどsub以外のクレームで利用者を特定できる設定項目（“oidc.user_id_claim” (https://github.com/anthropics/claude-code/releases/tag/v2.1.312)）が追加された。全画面表示時に送信待機中メッセージ下の案内クリックで即時送信が可能となった。長大なCLAUDE.mdや規則ファイルの冒頭のみを読み取った状態で全体を上書きしてしまう不具合を防ぐため、Writeツールが全文読取または差分編集を求める挙動に改められた。リポジトリ深部への移動後に特定パスのスキルが探索できなくなる問題や、VS Code拡張機能からの認証後に組織設定が取得されない問題、遅延したGitHubイベントでも最新コミットをコードレビューする修正、セッション当たりのフック同時実行数を最大24件に制限する仕様変更などが施された。
