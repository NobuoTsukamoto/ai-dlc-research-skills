#### [Selected models in GitHub Copilot deprecated](https://github.blog/changelog/2026-10-02-selected-models-in-github-copilot-deprecated)

- 公開日: 2026-10-02
- バージョン / 提供段階: なし / stable
- 重要度: high
- 変更内容（要約）: GitHub Copilotの全機能（チャット、インライン編集、ask/agentモード、コード補完）において、Gemini 3.5 Flash、Gemini 3.6 Flash、Kimi K2.7 Code、Claude Opus 4.7の4モデルが非推奨化された。GitHubは代替モデルとしてGemini 3.8 Flash、Kimi K3、Claude Opus 5.5の利用を推奨している。Enterprise管理者はCopilot設定のモデルポリシーで代替モデルへのアクセス許可を確認する必要がある場合がある。公式記述: “deprecated the following models across all GitHub Copilot experiences” ([canonical URL](https://github.blog/changelog/2026-10-02-selected-models-in-github-copilot-deprecated))
- 制約: 全Copilot機能が対象。Enterprise環境では管理ポリシーによる代替モデルの明示的有効化が必要な場合あり。非推奨モデルの削除に利用者側での操作は不要。
- 実務への影響（推論）: 旧モデルを指定している自動化スクリプトやカスタムプロンプト、設定ファイルは代替モデルへの移行が必要になる。Enterprise環境では組織のポリシー設定によって新モデルが無効化されている可能性があるため、開発者が利用を継続できるよう管理者が事前に許可設定を確認しておくと混乱を防ぎやすい。

#### [Copilot code review: API support and new default effort level](https://github.blog/changelog/2026-10-02-copilot-code-review-api-support-and-new-default-effort-level)

- 公開日: 2026-10-02
- バージョン / 提供段階: なし / stable
- 重要度: medium
- 変更内容（要約）: RESTおよびGraphQL API経由でGitHub Copilotコードレビューをリクエスト可能になった。API経由のリクエスト時にレビュー強度（review effort level）を指定できる。あわせて、コードレビューの既定の強度設定が「Balanced」へ変更された。過去に明示的に「Lite」を選択していた設定は維持される。Pro、Pro+、Max、Business、Enterpriseの各プランで一般提供（GA）されている。公式記述: “Balanced is also now the default review effort level” ([canonical URL](https://github.blog/changelog/2026-10-02-copilot-code-review-api-support-and-new-default-effort-level))
- 制約: Copilot Pro、Pro+、Max、Business、Enterpriseプランが対象。一般提供（GA）。Lite設定はEnterprise設定（AI controls → Agents → Copilot code review）またはOrganization設定（Copilot → Code review）から変更可能。
- 実務への影響（推論）: 独自のCI/CDパイプラインや社内開発ツールから直接Copilotのレビューを実行できるようになり、プルリクエスト作成時の自動検査に組み込みやすくなる。既定のレビュー強度がBalancedになったことで、指摘の網羅性が向上する一方、コメント数の増加に伴う確認負担の変化に留意する必要がある。
