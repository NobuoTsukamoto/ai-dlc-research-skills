### GitHub Copilot CLI

#### [Copilot CLI 1.0.92](https://github.com/github/copilot-cli/releases/tag/v1.0.92)

- 公開日: 2026-10-05
- バージョン / 提供段階: 1.0.92 / stable
- 重要度: high
- 変更内容（要約）: Copilot CLIの安定版1.0.92がリリースされた。設定の一覧表示・取得・設定・削除を行う “copilot config subcommands to list, read” ([canonical URL](https://github.com/github/copilot-cli/releases/tag/v1.0.92)) が追加された。対話開始前にローカル実行とクラウド実行を切り替えるCtrl+Eの環境選択機能が加わった。サンドボックス実行では明示設定がない限り環境のGITHUB_TOKENを遮断し、Git実行時の認証情報マスクとSSH書き換えに対応した。またEntra保護MCPサーバーでのアクセストークン自動更新、HTTP+SSE接続の無応答タイムアウト、プロバイダー容量超過時の画像縮小再試行、コンテキスト超過時の最新プロンプト保持、巨大ファイル生成後のセッション停滞の解消、子プロセス展開による初回起動高速化、サンドボックス内でのuvやpnpmの権限エラー解消など多数の改善が適用された。
- 制約: 安定版（stable）。サンドボックス制限はサンドボックス実行環境が対象。対話前環境ピッカー（Ctrl+E）は対話開始前の画面で動作。
- 実務への影響（推論）: copilot config サブコマンドによってCIや自動環境構築スクリプトからのCLI設定管理が容易になる。対話開始前にローカルとクラウドの実行基盤をCtrl+Eで直接切り替えられるため、計算資源やセキュリティ要件に応じた環境選択を対話ごとに行いやすい。サンドボックス内でGITHUB_TOKENの自動引き渡しが制限されたことで、サードパーティ製ツールや外部リポジトリを操作するエージェント作業の安全性が向上する。また、巨大ファイルの生成による停止やコンテキスト超過時の入力消失が解消され、自律実行タスクを長時間走らせる際の安定性が大きく高まる。

### Claude Code

#### [Claude Code v2.1.290](https://github.com/anthropics/claude-code/releases/tag/v2.1.290)

- 公開日: 2026-10-05
- バージョン / 提供段階: v2.1.290 / stable
- 重要度: high
- 変更内容（要約）: Claude Code v2.1.290がリリースされた。modのフック向けに “Added serverToolUses to the result” ([canonical URL](https://github.com/anthropics/claude-code/releases/tag/v2.1.290)) やagentId、ceilingフィールドを追加した。セキュリティ面では、作業ディレクトリ外へリンクされたCLAUDE.mdやAGENTS.mdが読み取り拒否規則を迂回する問題を修正した。またBashツールでのpyright実行を読み取り専用扱いから外し承認を求めるように変更し、psコマンドの承認対象を広げたほか、リポジトリ設定での添付無効化オーバーライドを禁止した。WebSearchでは200回制限を改め毎時100回の補充型へ移行した。WebFetchは10万文字超過時にオフセット指定で続きを読めるようにした。さらに巨大セッション再開時の応答性改善、中断されたサブエージェントの思考やプロンプトキャッシュ保持、VS Code拡張でのメッセージ待機アナウンス追加など多数の修正を行った。

- 実務への影響（推論）: 作業ディレクトリ外のシンボリックリンクを用いた設定ファイル読み取り制限の迂回が塞がれ、マルチプロジェクトや共有リポジトリ環境でのセキュリティが強化される。一方、これまで無確認で実行できたpyrightやpsコマンドが承認を求めるようになるため、スクリプトやCI等で自動化している環境では権限設定の見直しが必要になる場合がある。WebSearchのレート制限が毎時補充型へ移行したことで、長時間の調査作業でも検索予算が枯渇しにくくなり、WebFetchの長文取得対応と合わせて情報収集エージェントの作業継続性が向上する。
