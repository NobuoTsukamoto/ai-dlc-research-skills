### GitHub Copilot

#### [Copilot code review: New organization billing options and controls](https://github.blog/changelog/2026-10-08-copilot-code-review-new-organization-billing-options-and-controls)

- 公開日: 2026-10-09
- バージョン / 提供段階: stable
- 重要度: high
- 変更内容（要約）: Copilot code reviewの管理者に向け、課金先とレビュー要求権限を制御する新設定が追加された。“bill Copilot code reviews” ([canonical URL](https://github.blog/changelog/2026-10-08-copilot-code-review-new-organization-billing-options-and-controls)) 設定により、組織管理者はメンバー個人のクォータ消費（Member）か、リポジトリ所有組織のコストセンターへの課金（Organization）かを選択できる。Organization課金には組織側でのAI Credits従量課金の有効化が必要であり、月額予算を設定できる。さらに、外部ライセンス（個人ライセンスなど）を持つユーザーからのレビュー要求を拒否し、組織またはEnterpriseから付与されたライセンスを持つユーザーに限定する設定が導入された。
- 制約: 安定版（stable）。Organization課金の利用には組織でのAI Credits有料利用の有効化が必要。組織レベルで外部ライセンスのレビュー要求を遮断した場合、リポジトリ管理者は個別解除できない。
- 実務への影響（推論）: 開発者の個人クォータ枯渇によるコードレビューの停止を防ぎ、組織の予算枠でレビュー実行を継続できる。組織外の個人アカウントや外部委託先からの不要なレビュー実行を遮断できるため、AI Creditsの予算管理と意図しないコスト膨張の抑止が容易になる。

### GitHub Copilot CLI

#### [Copilot CLI 1.0.95](https://github.com/github/copilot-cli/releases/tag/v1.0.95)

- 公開日: 2026-10-09
- バージョン / 提供段階: 1.0.95 / stable
- 重要度: high
- 変更内容（要約）: Copilot CLI 1.0.95がリリースされた。macOS環境において“Entra broker authentication” ([canonical URL](https://github.com/github/copilot-cli/releases/tag/v1.0.95)) に対応し、ブローカー不在時はブラウザ認証へフォールバックする仕様となった。copilot configコマンドでサンドボックス資格情報のinjectHostsキー設定をサポートし、Bash、Zsh、Fishでのキー補完に対応した。ACPセッションの新規開始および再開時に、既定値や保存値への暗黙フォールバックを廃止して--contextオプションが正確に適用されるよう改修した。また、管理対象プラグインのセットアップ処理において、メッセージ送信失敗ごとの再試行をやめ、毎時またはポリシー変更時に再試行する方式に改めた。
- 制約: 安定版（stable）。macOS向けEntraブローカー認証はシステム側にブローカーが存在する場合に有効。
- 実務への影響（推論）: macOSでの企業アカウント認証がOS標準のブローカーと統合され、端末ごとの認証フローの手間が軽減される。サンドボックス内の外部ホスト認証設定がコマンド補完付きで安全に構成可能になる。ACPセッションで指定したコンテキスト規模が確実に反映されるため、長大なログ解析や大規模編集での予期せぬコンテキスト不足を防ぎやすくなる。

### Claude Code

#### [Claude Code v2.1.295](https://github.com/anthropics/claude-code/releases/tag/v2.1.295)

- 公開日: 2026-10-09
- バージョン / 提供段階: v2.1.295 / stable
- 重要度: high
- 変更内容（要約）: Claude Code v2.1.295がリリースされた。コマンドおよびHTTPフックに“onFailure: "block"” ([canonical URL](https://github.com/anthropics/claude-code/releases/tag/v2.1.295)) が追加され、フックの起動失敗やタイムアウト、予期しない終了コードの発生時に対象アクションを遮断できるようになった。端末の状態表示規格であるProgram Status Protocol（OSC 7501）に対応した。Claude apps gatewayでは上流プロバイダーの初回トークン応答待ち時間を制限するtimeouts.upstream_ttfb_ms、gateway強制ログイン（forceLoginMethod: gateway）をサポートした。不具合修正として、[1m]モデルでbetaフラグ拒否時の自動再送、リモートMCP切断時の指数バックオフ、MCPツールの拡張子判別の適正化、サブエージェント専用worktreeでの親Git情報の混入防止などが適用された。
- 制約: 安定版（stable）。onFailure: blockはコマンドフックおよびHTTPフックが対象。OSC 7501は対応ターミナルエミュレーターでのみ表示。
- 実務への影響（推論）: フックの障害時フェイルクローズ（遮断）が可能になり、セキュリティ検査や規約チェックの不備による危険な操作のすり抜けを防止できる。長時間の自律実行中に端末タブ上で稼働状態（実行中・待機中・完了）を把握しやすくなる。また、1Mモデルの通信リトライやMCPの再接続が安定し、大規模リファクタリングセッションでの中断トラブルを低減できる。
