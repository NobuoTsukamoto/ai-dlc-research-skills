#### [HydraFusion updates and new Max option](https://github.blog/changelog/2026-10-14-hydrafusion-updates-and-new-max-option)

- 公開日: 2026-10-15
- バージョン / 提供段階: preview (research preview)
- 重要度: high
- 変更内容（要約）: 複数モデルを協調動作させるHydraFusionのモデルプールが更新され、Claude Opus 5.5、GPT-6 Astra、GPT-6.1 Sol、GPT-6 Lunaが追加された。各工程に応じて推論強度を個別に調整する仕組みが導入され（“tailors effort to each stage” ([canonical URL](https://github.blog/changelog/2026-10-14-hydrafusion-updates-and-new-max-option))）、ドラフト作成には中程度の推論、レビューには高い推論が割り当てられる。また、初期結果を判定して必要な場合のみ修復を求める処理や、ワークスペースへの直接ツール検査、並列クリティックモデルによる評価が追加された。さらに、より高度な推論を必要とする要求の高いタスク向けに「HydraFusion Max」が新設された。
- 制約: Copilot Pro、Pro+、Business、Enterpriseプランでプレビューまたは実験的機能を有効にしている利用者が対象。組織のモデルポリシーに従う。VS Code、GitHub Copilot app、GitHub Copilot CLIで利用可能。
- 実務への影響（推論）: 開発者がタスクごとに個別モデルを選択し分ける手間を省きつつ、高品質なコード生成と検証を自動化できる。初期草案の速度を維持しながらレビュー工程に深い推論を集中させるため、回答の精度向上と待機時間のバランスが改善する。難度の高い設計やリファクタリングではHydraFusion Maxを活用することで、手戻りの少ないコード修正が期待できる。

#### [Agentic autofix for code scanning alerts general availability](https://github.blog/changelog/2026-10-15-agentic-autofix-for-code-scanning-alerts-general-availability)

- 公開日: 2026-10-15
- バージョン / 提供段階: stable
- 重要度: high
- 変更内容（要約）: コードスキャン警告を自律的に修復するAgentic autofixが一般提供（GA）された。警告をCopilotに割り当てると、開発者のようにコードベースを横断探索し（“working across your codebase the way a developer would” ([canonical URL](https://github.blog/changelog/2026-10-15-agentic-autofix-for-code-scanning-alerts-general-availability))）、修正案を生成してCodeQLで警告解消を自動検証した上でドラフトPRを作成する。PR作成後はコメントや専用セッションで追加指示が可能である。デフォルトブランチ上のアラートを対象に、個別画面またはセキュリティ一覧から最大25件を選択して1つのPRにまとめて修正できる。実行にはCode Security予算のAI CreditsとActions実行時間を消費する。
- 制約: GitHub Enterprise Cloud上のGitHub Code SecurityまたはGitHub Advanced Securityの契約が必要。Enterprise管理者がポリシーで有効化し、組織またはリポジトリで設定を有効にする必要がある。Copilotの請求設定（AI Credits）が必要。デフォルトブランチのアラートのみ対象（PR検出分は対象外）。最大25件まで一括修正可能。
- 実務への影響（推論）: セキュリティ修正にかかる開発者の調査・修正・検証の負荷を大幅に削減できる。特に修正案の提示にとどまらず、CodeQL再実行による修正確認まで完了した状態でPRが作成されるため、脆弱性対応のリードタイム短縮につながる。一方でAI CreditsとActions実行時間が消費されるため、組織内での適用ルールや予算上限の設定が推奨される。
