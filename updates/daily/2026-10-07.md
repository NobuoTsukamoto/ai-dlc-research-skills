### GitHub Copilot

#### [Local sandboxing for GitHub Copilot now generally available](https://github.blog/changelog/2026-10-07-local-sandboxing-for-github-copilot-now-generally-available)

- 公開日: 2026-10-07
- バージョン / 提供段階: stable
- 重要度: high
- 変更内容（要約）: Copilot CLI、GitHub Copilot app、VS Code（Agent Host経由）においてローカルサンドボックスが一般提供された。Microsoft eXecution Container（MXC）を基盤とし、OSのネイティブ制御を介して共通ポリシーを適用する。“secure execution boundary for agentic workflows” ([canonical URL](https://github.blog/changelog/2026-10-07-local-sandboxing-for-github-copilot-now-generally-available)) を提供し、ファイル読み書き制限、ネットワーク通信制御、GitやGitHub CLIの認証情報保護、ローカルMCP分離を行う。Enterprise管理設定によるポリシー強制にも対応する。追加料金なしで利用できる。
- 制約: Windows、macOS、Linuxに対応。モデル実行自体ではなくエージェントが呼び出すツールやコマンドの実行分離に適用される。Enterprise組織では管理設定により開発者による緩和を禁止できる。
- 実務への影響（推論）: 開発者のローカル環境で自律エージェントにシェルコマンドやファイル変更を実行させる際、OSレベルの分離によって破壊的操作や資格情報の漏洩リスクを抑止できる。企業管理者が設定を統一強制できるため、機密リポジトリを扱う環境にもエージェント運用を拡大しやすい。追加料金なしで利用できるため、導入に伴うコスト負担の懸念も少ない。

#### [Claude Haiku 5.5 in GitHub Copilot](https://github.blog/changelog/2026-10-07-claude-haiku-5-5-in-github-copilot)

- 公開日: 2026-10-07
- バージョン / 提供段階: stable
- 重要度: high
- 変更内容（要約）: Anthropicの軽量モデルClaude Haiku 5.5がGitHub Copilotで一般提供された。“fast, high-volume work like subagents” ([canonical URL](https://github.blog/changelog/2026-10-07-claude-haiku-5-5-in-github-copilot)) 向けに設計されており、初期テストではClaude Sonnet 5と同等のコーディング性能を少ないトークン数とステップ数で発揮したとされる。VS Code、Visual Studio、Copilot CLI、cloud agent、app、Web、モバイル、各種IDEから選択可能。Copilot Pro、Pro+、Max、Business、Enterpriseで従量課金制の下で提供される。管理者はモデルポリシーで有効化を管理できる。
- 制約: 段階的展開。従量課金制（usage-based billing）に基づく追加料金が発生する。EnterpriseおよびBusinessプランでは管理者がモデルポリシーで利用可否を制御可能。
- 実務への影響（推論）: サブエージェントや定常的な小規模編集タスクをHaiku 5.5へ割り振ることで、Sonnet 5水準のコード品質を維持しつつ応答速度の向上とトークン消費の抑制を両立できる。大量のファイル編集や継続的インテグレーションでの自動処理など、呼び出し頻度が高い作業フローでの運用コスト低減を見込める。
