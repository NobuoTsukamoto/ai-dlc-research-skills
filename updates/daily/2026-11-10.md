### GitHub Copilot CLI

#### [C++ language server now auto-configures MSBuild builds](https://github.blog/changelog/2026-11-10-c-language-server-now-auto-configures-msbuild-builds)

- 公開日: 2026-11-10
- バージョン / 提供段階: stable
- 重要度: medium
- 変更内容（要約）: Copilot CLI向けMicrosoft C++ Language ServerがMSBuild用compile commands extractorを同梱し、project open時に自動実行する。MSBuildでは手動の`compile_commands.json`生成や設定skillが不要になる。
- 制約: 有効なGitHub Copilot subscriptionとC++ Language Serverのインストール、EULAへの同意が必要。対象はMSBuildで、CMakeや独自buildには従来の設定手順が残る。
- 実務への影響（推論）: MSBuildを使うC++ repositoryでは、定義移動や参照検索を始める前の設定作業とagentによる設定探索が減る。
