#### [BYOK and enterprise custom models in the Copilot usage API](https://github.blog/changelog/2026-11-03-byok-and-enterprise-custom-models-in-the-copilot-usage-api)

- 公開日: 2026-11-04
- バージョン / 提供段階: Usage metrics API / stable
- 重要度: medium
- 変更内容（要約）: Copilot usage metrics APIに、Copilot CLI・Copilot appのlocal BYOK利用量や利用者数と、組織独自モデルの要求・token数を区別する項目が加わった。
- 制約: 利用にはCopilot metricsの参照権限とusage metrics policyの有効化が必要。local BYOKはtelemetryやproviderのtoken報告状況により過少集計される場合がある。過去日のcustom-model識別情報は補完されない。
- 実務への影響（推論）: 管理者はCopilot提供モデルと自社キー・独自モデル経由の利用を分けて利用状況や費用を見積もれる。local BYOKの数値だけで費用を精密に照合するのは避けたい。

#### [GitHub Copilot is now available in JetBrains Air](https://github.blog/changelog/2026-11-03-github-copilot-is-now-available-in-jetbrains-air)

- 公開日: 2026-11-04
- バージョン / 提供段階: JetBrains Air連携 / 明記なし（JetBrains pluginはAir Alpha）
- 重要度: medium
- 変更内容（要約）: JetBrains Airのagent pickerからGitHub Copilotを選び、IDE内またはcloud taskに利用できるようにした。cloud taskはAir TeamsのDocker containerで実行され、JetBrains AI creditsではなくCopilot planを使う。
- 制約: cloud taskにはAir Teams対応business organization、GitHub Copilot subscription、管理者によるCopilot有効化が必要。Airのgovernance・analyticsはCopilot利用量を含まず、Air上でspending limitを設定できない。taskごとに個人・組織planを選ぶこともできない。
- 実務への影響（推論）: JetBrains IDE内の作業と隔離されたcloud taskを同じCopilot subscriptionで選べる。組織はAir上で利用量や支出を管理できないため、別のCopilot管理手段との役割分担を決める必要がある。
