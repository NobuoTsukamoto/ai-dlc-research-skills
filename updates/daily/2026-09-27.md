### GitHub Copilot CLI

#### [Copilot CLI 1.0.89-5](https://github.com/github/copilot-cli/releases/tag/v1.0.89-5)

- 公開日: 2026-09-27
- バージョン / 提供段階: 1.0.89-5 / prerelease
- 重要度: medium
- 変更内容（要約）: ユーザー入力フォーム（ask_userなど）を左クリックした際にフォーカスを当て、クリック位置へカーソルを合わせる操作改善を行った。`.claude/rules` ディレクトリ内のClaude Code向けルールファイルをカスタム指示（custom instructions）として認識する機能を追加した。サイドバーでは、未確認の完了ターンが存在するセッションに青丸インジケーターを表示するようにした。加えて、管理MCPポリシーの適用中にEnterprise管理設定下で拡張機能の読み込みが失敗する問題、Git 2.36以降で空の環境変数が除外された際にCLI配下のアプリケーションでGit操作が失敗する問題、サンドボックス内のエージェントがセッションファイルやログへアクセスできない問題を修正した。
- 制約: プレリリース（pre-release）。Claude Codeルールファイルの読み込みは `.claude/rules` ディレクトリが存在する環境が対象。
- 実務への影響（推論）: Claude Code向けに整備した指示ファイルをCopilot CLIで再利用できるため、複数のエージェントを併用する開発現場で指示の二重管理を回避できる。サイドバーの未読表示や入力フォームのフォーカス改善により、複数セッションを並行実行する際の操作性が向上する。管理MCP適用環境での拡張読み込みやサンドボックス内でのログアクセス修正により、企業環境におけるエージェント実行の安定化が期待できる。機能名は「`.claude/rules`」（[canonical source](https://github.com/github/copilot-cli/releases/tag/v1.0.89-5)）。

### Google Antigravity CLI

#### [Antigravity CLI 1.2.12](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.2.12)

- 公開日: 2026-09-27
- バージョン / 提供段階: 1.2.12 / stable
- 重要度: medium
- 変更内容（要約）: フルスクリーン表示時のスクロール描画処理を合流（coalesce）させ、長文の対話や成果物ビューアでのCPU負荷とスクロール遅延を低減した。`GEMINI_API_KEY` を用いたセッションにおいて、API側から日次クォータの枯渇や請求上限への到達、事前チャージ枠の不足が返された際は、長時間の再試行を行わず即座に処理を停止するように改善した。会話履歴の再開時にツール呼び出しの再アニメーションを省いて完了状態で復元する修正や、GNU screenやtmuxなどの端末マルチプレクサ起動時に端末タイトルが書き換わる不具合の修正、Vimモードにおける非ASCII文字処理やUndo履歴の不具合修正を行った。
- 制約: `GEMINI_API_KEY` セッションの即時停止は日次枠超過や請求上限が対象であり、一時的な分単位のレート制限は再試行を維持する。端末マルチプレクサ環境で画像を強制表示する場合は `CLI_GRAPHICS=kitty` の明示指定が必要。
- 実務への影響（推論）: APIの利用枠が枯渇した際に無駄な再試行ループで待たされる時間がなくなり、認証情報やモデルの切り替え判断を迅速に行える。長時間の対話セッションを再開する際の待機時間やスクロール時の描画遅延が解消され、端末上での対話作業を滞りなく進めやすくなる。tmuxやscreenなどの環境でも端末タイトルが汚損されず、普段の開発環境を維持しやすい。機能名は「`GEMINI_API_KEY`」（[canonical source](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.2.12)）。
