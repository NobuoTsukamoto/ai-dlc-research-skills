### Claude Code

#### [Claude Code v2.1.302](https://github.com/anthropics/claude-code/releases/tag/v2.1.302)

- 公開日: 2026-10-17
- バージョン / 提供段階: 2.1.302 / stable
- 重要度: medium
- 変更内容（要約）: Claude Code v2.1.302が安定版としてリリースされた。クライアント側の自動判定モデルを指定する環境変数（“client-side auto mode classifier” ([canonical URL](https://github.com/anthropics/claude-code/releases/tag/v2.1.302))）としてCLAUDE_CODE_AUTO_MODE_MODELが追加されたほか、/configにアイドル時コンパクションの有効・無効を切り替える項目が導入された。またfork型サブエージェントがclaude -pやAgent SDK、デスクトップアプリ、VS Codeで既定有効化され、デスクトップアプリとVS Codeでは主会話のサブエージェントが端末同様に既定でバックグラウンド実行されるよう変更された。さらにReadツールによる128MB超の画像読み込み拒否、フック実行の同時並行数上限（最大12件）、単体版Claude Designの2026年12月終了予告、各種不具合修正が行われた。
- 制約: 安定版（stable）。Node.js環境でのnpmパッケージ更新で利用可能。一部機能は環境変数または/configでの設定が必要。
- 実務への影響（推論）: 自動判定に用いる分類器モデルを個別に選定できるようになり、軽量モデルの指定による判定遅延やAPI消費の抑制が可能となる。fork型サブエージェントが各種実行面で既定有効化されたことで、コンテキストを複製した並行作業を明示的な引数指定なしに利用しやすくなる。またデスクトップやVS Codeでのサブエージェント背景実行への統一により、長時間タスク実行中のUI応答性が改善する。Readツールのサイズ制限やフック並行数の制限は、リソース枯渇による予期せぬクラッシュの抑止につながる。
