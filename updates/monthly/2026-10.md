# AIコーディングエージェント月次まとめ 2026-10

## エグゼクティブサマリー

- 10月は、Copilot Fusionや複数エージェント機能など、モデルやエージェントを組み合わせる仕組みが増えた。同時に、サンドボックス、権限設定、管理API、利用状況の計測も整備された。
- 各社に共通した流れは、自律実行の範囲を広げながら、管理者が実行権限、利用モデル、費用を制御する機能を追加することだった。安定版とpreviewが混在するため、機能ごとの提供段階を見分ける必要がある。

## 主要アップデート

### 自律実行の安全統制と組織管理

- 対象ツール: GitHub Copilot, GitHub Copilot CLI, GitHub Copilot app, Claude Code, Google Antigravity CLI, OpenAI Codex
- 変更内容（要約）: Copilotではローカルサンドボックスが一般提供となり、Assisted Permissionsも一般提供された。管理者向けのモデルポリシーAPIや既定値の強制、利用状況APIも拡張された。Claude Codeはサンドボックス迂回などを修正して安全イベントの記録を追加し、Antigravity CLIは機密ディレクトリの既定保護やURLごとの承認を強化した。Codexもリモート実行時の認証情報マスキングを加えた。
- 変化の方向: 月初のpreview提供や個別の実行制限から、月末には一般提供と組織単位の設定・監査へ進んだ。各製品で提供範囲や既定値は異なる。
- 実務への影響（推論）: 自律実行を導入する際、承認方式だけでなく、サンドボックス境界、組織ポリシー、利用記録を一緒に確認できるようになった。管理者は既定値の変更と、個別の開発環境で有効な設定が一致しているかを確認したい。
- 公式ソース: [Copilot local sandboxing GA](https://github.blog/changelog/2026-10-07-local-sandboxing-for-github-copilot-now-generally-available), [Assisted Permissions GA](https://github.blog/changelog/2026-10-26-github-copilot-assisted-permissions-generally-available), [Copilot model policy API](https://github.blog/changelog/2026-10-19-copilot-model-policy-api-for-enterprise-orgs-and-teams), [Claude Code v2.1.309](https://github.com/anthropics/claude-code/releases/tag/v2.1.309), [Antigravity CLI 1.4.9](https://github.com/google-antigravity/antigravity-cli/releases/tag/1.4.9)

### 複数エージェントと開発環境の拡張

- 対象ツール: GitHub Copilot, GitHub Copilot app, GitHub Copilot CLI, OpenAI Codex, Cursor
- 変更内容（要約）: CopilotではDynamic workflowsのpreview、Copilot Fusionの一般提供、Memory、共有Automations、pluginの組織管理が進んだ。Copilot appにはProjectsやComputer Use、security extensionのpreviewが加わった。Codex CLIは実行中の指示変更、worktree管理、Vertex AI接続を追加し、CursorはRemote control、外部サービス連携、Cloud Agent向けAPIを公開した。
- 変化の方向: 単一セッション内のコード生成から、複数エージェントの連携、作業の継続、外部サービスとの接続へ対象が広がった。CopilotのMemoryやAutomation、CursorのEnvironments APIなどは、一般提供とpreview・betaが混在する。
- 実務への影響（推論）: 反復作業や複数リポジトリの処理を共有しやすくなる一方、セッションの権限、外部連携先、実行端末、料金の責任範囲を決める必要がある。previewやbetaは、既存運用の置き換えではなく限定した試行から始めるのが妥当である。
- 公式ソース: [Copilot Fusion](https://github.blog/changelog/2026-10-28-route-and-orchestrate-models-with-github-copilot-fusion), [Copilot Automations](https://github.blog/changelog/2026-10-28-build-shared-workflows-for-your-team-with-copilot-automations), [Copilot app Universe releases](https://github.blog/changelog/2026-10-28-github-copilot-app-universe-releases), [Codex CLI 0.163.0](https://github.com/openai/codex/releases/tag/rust-v0.163.0), [Cursor Cloud Agent updates](https://cursor.com/changelog/cloud-agent-canvases-and-environments)

### モデルの入れ替えと費用管理

- 対象ツール: GitHub Copilot, OpenAI Codex, Claude Code
- 変更内容（要約）: Copilotは複数モデルを追加する一方、旧モデルの廃止と11月の廃止予定を告知した。CodexではGPT-5.5の提供終了とGPT-6.1系の追加があり、Claude CodeはSonnet 5.5とHaiku 5.5を標準モデルに採用した。利用料金では、CopilotのAIクレジット、コードレビューの組織課金、Usage metrics APIによる計測範囲の拡大が進んだ。
- 変化の方向: モデルの選択肢が増えるのと並行して、旧モデルの退役、従量課金、組織の予算管理が具体化した。
- 実務への影響（推論）: 固定モデル名を指定する設定や自動化は、廃止日より前に後継モデルで検証したい。モデル選択を自動化する場合も、選ばれるモデルと費用の上限を把握できる計測・管理設定が必要になる。
- 公式ソース: [Selected Copilot models deprecated](https://github.blog/changelog/2026-10-02-selected-models-in-github-copilot-deprecated), [Upcoming Copilot model deprecations](https://github.blog/changelog/2026-10-15-upcoming-deprecation-of-selected-github-copilot-models-in-mid-november), [GPT-5.5 retirement in Codex](https://learn.chatgpt.com/codex/models), [GPT-6.1 Terra in GitHub Copilot](https://github.blog/changelog/2026-10-26-gpt-6-1-terra-in-github-copilot)
